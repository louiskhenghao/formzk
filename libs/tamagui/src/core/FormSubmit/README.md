# FormSubmitButton

Tamagui `Button` wired to the form context's submit handler. Also available as `Formzk.Tamagui.Submit`. Disabled automatically while the form is loading, submitting or validating.

---

## Example

```tsx
import { Formzk } from '@formzk/tamagui';

<Formzk.Tamagui.Submit text="Save" theme="blue" size="$5" />;
```
